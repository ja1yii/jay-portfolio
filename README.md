# Jay Hatmode — Personal Portfolio

A responsive, single-page personal portfolio built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — responsive dark theme and visual styling
- `script.js` — mobile navigation and dynamic footer year

## Run locally
1. Extract this folder.
2. Open `index.html` in a browser, or open the folder in VS Code.
3. For a convenient local preview, use the VS Code **Live Server** extension and click **Go Live**.

## Publish with GitHub + Vercel
1. Create a public GitHub repository, for example `jay-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Sign in to [Vercel](https://vercel.com/) with GitHub.
4. Select **Add New → Project**, import `jay-portfolio`, and deploy.
5. No build command is required for this static HTML/CSS/JS site. Set the framework preset to **Other** if asked.

## Before publishing
- Confirm all education details, skills, and project descriptions are accurate.
- Add a working project URL for SecurePoll and the two project concepts when you publish them.
- Add a resume PDF if you want a working resume download link. The current site intentionally does not include a fake or broken download button.
- Your LinkedIn, GitHub, and email links are included.
